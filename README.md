Syber Tickets is a Web3 ticketing platform that redefines event ticketing through smart contracts and soulbound NFTs. The system issues non-transferable NFT-based tickets, ensuring tickets remain permanently tied to the buyer and eliminating the possibility of scalping.

Through a simple web interface, any Web3 wallet user can create events, manage ticket sales, and purchase tickets directly on the platform. Users can also view and track their tickets in one unified dashboard experience.

The goal of Syber Tickets is to provide an intuitive, scalable ticketing solution for both small and large events, combining blockchain transparency with a seamless user experience while significantly reducing fraud and secondary market abuse.


The Project will incorporate the following technologies:  HTML5, CSS3, Solidity, Javascript, React,, Redux, and Hardhat
